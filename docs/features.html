00整套系統怎麼運作

第一次接觸的人，先看懂這一節就夠了。

整套系統其實只有一個資料庫，差別在於「誰從哪個門進來看它」。同一位個案的預約、晤談、費用都是同一筆資料，所以櫃檯排的約，個案在手機上看得到、心理師行事曆上也會出現，不必任何人重打一次。

三個入口，三種人

員工端（要登入）

櫃檯、心理師、督導、所長用的完整後台。網址 /，帳號密碼登入，看得到什麼由權限決定。

個案專區（要登入）

個案自己的手機頁面。網址 /portal.html，用手機號碼登入，只能看預約、費用、量表、同意書——看不到任何晤談紀錄。

線上預約表單（免登入）

網址 /booking.html，任何人打開就能填，送出的是「申請」，要櫃檯確認才算數。

三個入口都能安裝成手機或電腦上的 App：Android／Chrome 依畫面提示按「安裝」，iPhone 用 Safari 的「分享 → 加入主畫面」。安裝後從主畫面開啟、沒有網址列，用起來就像一般 App，資料仍是即時連線（見安裝成 App）。

另外還有一個不算「入口」的角色：LINE 官方帳號。它不是給人操作系統的地方，而是系統主動找個案的管道——送預約連結、發晤談提醒、傳收據。

一位個案從頭到尾會經過什麼

  1. 找上門。三種來法：打電話（櫃檯在「來電登記」記一筆）、從 LINE 按「開始預約」、或直接填線上表單／原本的 Google 表單。後兩者都會變成一筆預約申請躺在後台等櫃檯處理。
  2. 櫃檯確認。櫃檯看申請，確認方案、心理師、時段都可以，按下確認——這時系統才真的把預約寫進排程，並自動挑一間當下沒人用的諮商室（個案全程看不到諮商室資訊）。沒建過檔的人可以一鍵用申請資料建立個案檔。
  3. 提醒。晤談前（預設 24 小時）系統自動發提醒；心理師則在前一晚收到明天的行程。
  4. 晤談當天。櫃檯在「今日看板」按報到、完成；心理師事後寫晤談紀錄（SOAP 格式），簽核定稿後就不能再改，比照病歷。
  5. 算錢。按下「完成」的當下，系統依這筆預約用的方案自動扣一次方案額度、或直接開出收費單，金額不用人算。收了款就能開收據，也可以直接用 LINE 傳給個案。
  6. 後續。下次預約、量表追蹤、處遇計畫、結案與結案後追蹤，都掛在同一位個案底下；月底報表與心理師收支自動從這些紀錄結算出來。

三個貫穿全系統的規則

一、資料只輸入一次

來電登記填的聯絡方式，建檔時直接帶入；表單填的資料，建檔時直接帶入；晤談完成的紀錄，直接變成收費、報表與心理師報酬的來源。系統裡幾乎沒有需要「抄過去」的地方，抄寫就是出錯的地方。

二、晤談內容和行政資料分開

行政人員看得到誰、什麼時候、多少錢，但看不到談了什麼。這道界線寫在後端，不是把按鈕藏起來而已，而且每次調閱晤談紀錄都會留下誰在何時看了誰的紀錄。詳見第 7 節。

三、沒設定就不對外送

LINE 還沒串接完成時，所有本來要推播的訊息只會被記成「待人工發送」躺在系統裡，一個字都不會送到外面。這是刻意的：寧可漏發，不要把個資送到還沒設好的服務。

01LINE 怎麼開始預約

個案端最短的一條路：加好友、按按鈕、填表單。

  1. 個案加入官方帳號 @032cjyby 的當下，系統就自動回一張 Flex 卡片，上面有「開始預約」和「打電話給諮商所」兩個按鈕。
  2. 之後他隨時傳任何訊息（打「預約」也好、傳貼圖也好）都會再收到同一張卡片。按下「開始預約」就進到我們的表單。
  3. 已建檔的舊個案有兩條路：個案自己在個案專區「我的資料」就看得到加好友按鈕與專屬 6 碼綁定碼，按「開啟聊天室並帶入綁定碼」後訊息已填好、按送出即完成綁定；或由櫃檯發碼給他輸入。都不必手抄 userId。

關鍵設計：網址裡不放 userId

按鈕帶的是一次性連結 /booking.html?bk=<隨機token>（效期 3 天），網址裡不放 LINE userId——表單送出時才由後端拿 token 換回身分。這樣預約成立、晤談提醒、收據都推得回同一個人，而 userId 不會留在網址列或瀏覽紀錄裡。

要真的動起來，需要先完成串接。請到「系統 → LINE 官方帳號 → 串接設定」貼上 Channel access token 與 secret，並按「寫回 LINE 並測試」。在那之前，所有推播只會記成「待人工發送」，系統完全不對外連線，不會把個資送到未設定的服務。

串接設定頁做三件事

  • 頻道憑證：貼上 LINE Developers Console 的 Channel access token（long-lived）與 Channel secret；已存的權杖只顯示末四碼，不改就留原樣。按「驗證連線」會向 LINE 取回官方帳號名稱與 ID，確認打得通。
  • Webhook：按「寫回 LINE 並測試」，系統直接把 https://goodmoodpsy.crownai.ink/api/line/webhook 設定到 LINE 頻道並請 LINE 實際回打一次。同時記得到 LINE 後台關閉「自動回覆訊息」與「歡迎訊息」，改由本系統回覆。簽章以 channel secret 驗證，驗不過即忽略。
  • 通知時間與樣式：晤談提醒提前時數、心理師行程每日推播時間、Flex 卡片主色、放在卡片按鈕上的預約表單網址。

綁定管理：綁了可以解、解了可以再綁

同頁的綁定管理列出員工與個案的綁定狀態，每個人隨時可調整：

  • 未綁定者按產生綁定碼；已綁定者則有重新綁定（換手機、換 LINE 帳號時發新碼）與解除綁定兩顆按鈕，解除後隨時能再發碼綁回來。
  • 已綁定者會顯示綁定時間，看得出這組綁定是什麼時候建立的。
  • 發錯人或對方沒收到，可以把還沒使用的綁定碼直接作廢；同一個人重發新碼時舊碼自動失效，不會兩組碼同時流通。
  • 個案清單可依姓名／編號／電話搜尋，並切換「只看未綁定／只看已綁定」。

另有推播與紀錄分頁（手動推播、每筆推播結果與失敗原因）。

03線上預約表單

/booking.html：公開免登入的手機版表單，欄位順序比照所內原本的 Google 表單。

諮商方案 → 諮商主題 → 預約之心理師 → 時段 → 基本資料，三個選項欄位都是下拉式選單。

個案全程看不到諮商室

表單與個案專區都不出現空間資訊，諮商室由系統在成立預約時自動挑一間當下沒被占用的（見空間管理）。

時段先過濾再顯示

已排除被占用、請假與帶團體的時間，並依方案人次上限過濾；某週額滿時直接顯示「本週已排滿，下週起尚可預約」。

資格先擋

補助方案的年齡與年度次數在表單端就先擋，個案不會白填一輪才被退。

櫃檯確認才進排程

送出的是「預約申請」，櫃檯在「線上預約申請」頁確認後才寫進排程；未建檔者可一鍵由表單資料建檔。方案可個別設定免審。

送出後請加官方帳號

表單上與完成頁都寫明送出當下尚未完成預約，請加入 LINE 官方帳號，櫃檯確認後在 LINE 回覆，收到確認才算成立。沒填加好友連結時，系統自動用官方帳號 ID 組一組。

完成頁附一組綁定碼

只加好友的話，官方帳號還不知道這個 LINE 是誰、確認卡片推不出去。完成頁附一組 6 碼（3 天有效），個案貼進聊天室即與這筆申請綁定；櫃檯建檔時 LINE 綁定會一併帶到個案身上。沒傳也不影響，改以電話聯繫。

彈性選項

主題選「其他」可自填；心理師選「由諮商所安排」時不列時段，改請個案填可配合時段，由櫃檯排定後回覆。

文字都能改

表單欄位、注意事項與個資告知文字皆在系統設定可改，不必動程式。

多久以前才能約：三道門檻

不能「開放 12:00 的時段，客人 11:55 還約得到 12:00」。系統有三道門檻，同時生效、取最嚴格的那一道，對外表單與個案專區共用同一組設定。

設定欄位意思目前值例子
最早可約幾天後今天起算幾天內都不開放1填 1：今天是 9/3，最早只能約 9/4
前一天幾點後關閉隔天時段過了這個時間，隔天就整天關掉21:0020:59 還約得到明天，21:00 之後明天全關，最早變後天
晤談前至少幾小時才收線上預約離晤談開始不足這個時數的時段一律不開放（0＝不設）24填 24：現在是 9/3 10:00，9/4 09:00 那格就不會出現

怎麼設定

  1. 後台左側「系統」→「系統設定」，找到「線上預約表單（對外）」這一區。
  2. 三個欄位分別是「最早可約幾天後」「前一天幾點後關閉隔天時段（HH:MM，留空不設）」「晤談前至少幾小時才收線上預約」。你要的「保留多久緩衝」就是第三個，直接填小時數，例如 24。
  3. 按儲存即生效，不必重開系統。個案專區的預約與改期、對外表單的時段列表都會同步依新值過濾。
  • 不足門檻的時段直接不顯示，不是按下去才被退——個案不會看到約不到的時間。
  • 個案專區的「改期」也走同一道檢查，不會變成後門。
  • 只擋線上：櫃檯與心理師在後台排約完全不受限，臨時要加當天的約照樣排得進去（後台的「開始時間」本來就能自己打，不限於開放時段）。
  • 個案專區另有自己的「最早可約幾天後／最晚可約幾天內」（系統設定 →「個案專區」區），與上面三道一併取最嚴格者。

04Google 表單同步

所內原本的「好心情心理諮商所＿諮商預約表」不必停用。

在「系統 → Google 表單同步」頁產生密鑰、把頁面上的 Apps Script 程式碼貼到表單的指令碼編輯器並設定「表單提交時」觸發器，之後每一筆回應都會即時寫入後台的「線上預約申請」，櫃檯不必再謄一次。

  • 方案／主題／心理師以選項文字自動對應（會自動忽略「（50分鐘2000元）」這類價目說明）；對不到時仍收單，並在申請上標示「需人工指定」，資料不會掉。
  • 姓名、信箱、電話、生理性別、出生年月日、地址、身分證字號、緊急聯絡人三欄一併帶入，按「由申請資料建檔」時直接寫進個案基本資料。
  • 電話會正規化（去掉空白與破折號、+886 轉 0），舊個案以電話自動比對。
  • 同一筆回應重送不會產生第二筆（以 Google 的 response id 去重），可用 backfill() 把先前的歷史回應一次補進來。
  • 端點 POST /api/integrations/google-form，以共用密鑰驗證，密鑰可隨時重新產生。

兩邊可並行；差別是自建表單能即時擋掉資格不符與額滿的時段、能直接選時段，且會回推 LINE 通知。

05方案、額度與收支

收費不是一個數字，而是一組規則，因此獨立成「方案」。

方案設定的東西用途
金額／可選金額固定價，或像伴侶諮商那樣由預約時挑金額（3000／3600／4500）
方案給付、核銷名稱補助方案由公部門支付的部分，與個案自付差額分開記帳
晤談時長40／50／80 分鐘各方案不同，排約時自動算結束時間
年齡上下限、每人每年次數補助方案的資格控管（如 15-45 歲、一年 3 次）
每位心理師每週／每月人次名額分配（如一位心理師一週 6 人次）
心理師報酬抽成比例或固定鐘點費

方案底下再分主題（如伴侶溝通、親職教養），主題可覆寫金額；再往下是心理師費率，可針對某位心理師（甚至某位心理師的某個主題）另訂金額、報酬方式與人次上限。取價順序：心理師費率 → 主題 → 方案預設。全部在「系統 → 方案設定」頁自行增修，不必改程式。

目前建立的方案

  • 自費：個別 50 分鐘 2000、個別 80 分鐘 3000、婚姻伴侶／家庭 80 分鐘 3000（可選 3000／3600／4500）、通訊（視訊）諮商 50 分鐘 2000、親子／家長諮詢 80 分鐘 3000、LGBTQ+ 族群個別諮商 40 分鐘 1200（限 3 次）。
  • 補助（個案自付 200 元場地費，其餘由方案給付）：115 年度 15-45 歲青壯世代心理健康支持方案（一年 3 次、每位心理師每週 6 人次）、臺南市教師支持方案（6 次）、國軍心理健康方案（6 次）、臺南市政府員工協助方案（4 次）、1219 台北捷運心理健康支持方案、馬太鞍溪心理健康支持方案。
  • 諮商主題（11 項共用）：自我探索、情緒困擾、壓力調適、親密關係、原生家庭／親子關係、人際關係、生涯議題、心理疾患、創傷與失落、職場議題、其他。

額度控管

  • 個案年度次數：已用次數 = 系統內該年度有效預約 + 人工調整（他所已使用過的次數）。個案頁與預約表單都看得到用了幾次，用滿即擋下，只剩 1 次時提前警示。
  • 心理師人次上限：以週一起算的自然週計。額滿時錯誤訊息直接附上「下週（起日）尚餘 N 人次」，櫃檯與個案都能當場改約下週。
  • 兩種上限預設擋下（可改為僅警示）；櫃檯確認仍要排時可強制排入，該決定會寫進稽核軌跡。
  • 「方案人次」頁一次看完每位心理師在各限量方案的本週／本月用量，並可當場按「調整上限」改這位心理師在這個方案的每週／每月人次：沿用方案設定、不限、或另訂個別上限，表上會標示哪些是個別設定。調整只影響該心理師、記入稽核，已排入的預約不會被回頭取消。

每位心理師每月收支

「心理師收支」頁依方案別結算，全所合計以表格逐列列出（完成場次、服務總額、方案給付、個案自付與其中的場地費、心理師報酬、所方淨收、實收與未收），每列附一句怎麼算出來的說明；下方再按心理師分開列出各自的方案明細。心理師報酬在晤談完成當下鎖定，事後調整方案費率不會回頭改動已結算的月份。單一心理師的當月明細可列印對帳。

06收據

收費單是帳，收據是給個案的憑證，兩件事分開。

個案談完當下要就開一張，不要的話事後也能補開——「收據」頁的「待開立」清單直接列出已收款但沒開收據的收費單。

現金與轉帳分開看。收費頁與月報都有「收款方式分項」，列出各方式的筆數、收款金額、其中已退與淨額，月底對帳時分得出現金抽屜該有多少、銀行進帳多少；收款當下選錯，按該筆「編輯」就能更正，不必作廢重開。

  • 流水編號：前綴 + 年月 + 四碼序號（如 GM20260800001），作廢的號碼不回收。
  • 補印會累計次數與時間，事後查得到這張印過幾次。
  • 開錯不塗改：作廢並「重開」新號，新舊互相勾稽。
  • 個案端在「費用」頁看得到自己的收據編號，需要紙本時報編號給櫃檯補印。
  • 已綁定 LINE 的個案可直接把收據以 Flex 卡片傳過去。

06.5空間管理

全所只有 2-3 間諮商室，所以空間由系統盯著，不靠人記。

  • 諮商室清單在「系統設定 → 諮商室」維護：名稱、容納人數、備註，可新增、編輯、停用或刪除；曾被排過的空間會改為停用而不真的刪除，歷史紀錄才不會斷。
  • 自動指派：櫃檯排約時不必挑房間，系統會挑一間該時段沒被占用的；要指定也可以在預約中直接選。
  • 衝突擋下：同一間諮商室時段重疊即時擋下，晤談與團體場次一起算，不會兩組人撞同一間。
  • 排滿會講：所有房間都被占用時，系統會提示「此時段所有諮商室都已排滿，尚未指定空間」，不會靜悄悄留下一筆沒有場地的預約。
  • 今日空間使用：「今日看板」上方一眼看完每間房今天被誰、幾點到幾點用掉，整天空著的會標出來；到所卻還沒指定空間的晤談會列在下方提醒補指定。
  • 個案端完全看不到：預約表單、個案專區與寄出的通知都不含空間資訊。

06.6哪些東西可以改、可以刪

原則：行政與排程資料可自由增修刪；憑證與紀錄類只能作廢或重開，歷史不因刪除而斷。

06.7安裝成 App

不必上架 App Store，用瀏覽器就能把系統裝到主畫面。

員工端「好心情後台」

開啟 goodmoodpsy.crownai.ink 後安裝。長按 App 圖示可直接跳「今日看板」「預約排程」「線上預約申請」。

個案端「好心情」

請個案用手機開 /portal.html 後加入主畫面。圖示與員工端不同色，兩個 App 不會混淆。

Android／Chrome／Edge

開啟後畫面下方會跳出安裝提示，按「安裝」即可；也可用瀏覽器選單的「安裝應用程式」，或系統設定頁的安裝按鈕。

iPhone／iPad

用 Safari 開啟 → 分享 → 加入主畫面。iOS 沒有自動安裝功能，頁面會跳一次操作說明。

刻意不做離線

這是連線型 App：頁面本身與所有個案資料一律不存在裝置上，只快取樣式與程式碼這類靜態檔案，而且是「網路優先、連不上才退回快取」。手機掉了、被借走，App 裡也不會留下任何個案資料或舊畫面。

代價是斷網時打得開但看不到資料——考量到裡面是晤談與個案資料，這個取捨是刻意的。

改版會自己提醒

系統更新後，App 內會跳出「已有新版本／更新」，按一下就換到新版，不會卡在舊畫面。

07保密分層

心理諮商的核心限制是保密。系統把「行政資料」與「晤談內容」分成兩層。

資料層誰看得到
個案基本資料、預約、收費、同意書行政櫃檯、心理師、督導、管理者
晤談紀錄（SOAP）、處遇計畫僅主責心理師本人、督導、管理者
危機事件與通報心理師、督導、管理者（行政預設無權限）
  • 保密邊界由後端統一把關，所有讀取晤談內容的 API 都必須經過它，不是靠前端隱藏按鈕。
  • 每次調閱晤談紀錄都寫入稽核軌跡（誰、何時、看了哪位個案），管理者可於「稽核軌跡」頁查詢。
  • 個案端完全不提供任何晤談紀錄內容，只做預約、改期、取消、量表、費用、同意書與行政訊息；逾免收費期限的取消只會送出「取消申請」並通知櫃檯，是否計費由櫃檯決定。

08其餘功能模組

從來電進案到結案追蹤，一條龍在同一套資料上跑。

每日作業

  • 總覽：今日晤談、待補紀錄、高風險個案、量表警示、處遇計畫到期、待處理來電、明日待提醒、執照與契約到期；儀表板含近 6 個月完成晤談／實收金額／新收個案長條圖。
  • 我的工作台（心理師視角）：我的個案與高風險數、本週排程（含視訊連結）、服務量、待補紀錄與衡鑑報告、督導時數、繼續教育積分與執照更新倒數。
  • 預約排程與行事曆：週檢視與月檢視，同一心理師、同一諮商室、同一位個案的時段衝突即時擋下；年份打錯（早於一年前或超過兩年後）也會擋。行事曆可依心理師篩選、點任一天直接排約。
  • 排班設定（預約排程頁下方）：每週固定班 ＋ 逐週覆寫——固定班每週套用，某一週要調整就切到那一週單獨排，其他週不受影響，也可整週改回沿用固定班。手指可直接刷選（手機適用），不在格線上的時間（如 13:15-14:05）用「自訂時段」加入，同頁登錄請假。
  • 行事曆訂閱（.ics）：每位心理師一組 token 網址，可加入 Google／iPhone 日曆訂閱未來半年班表；只帶個案編號不帶姓名，網址可隨時重設。
  • 候補遞補：取消或未到釋出時段時，依「指定心理師 → 緊急度 → 希望時段吻合 → 等候天數」配對候補名單並一鍵發送遞補通知。
  • 線上視訊晤談：形式選「視訊」即帶入該心理師的固定會議室連結，自動附在提醒訊息中，雙方一鍵進入；視訊不佔用諮商室，空間表只呈現真正到所的晤談。
  • 今日看板：報到／完成／未到／取消一鍵處理；完成時自動扣方案次數或產生收費單，未到依比例計費。

個案服務

  • 來電登記與派案：來電 →（候補）→ 派案 → 初談建檔的完整漏斗，高風險來電標紅、等候超過 14 天示警。
  • 個案端自填初談問卷：免登入連結傳給來電者，填基本資料、主訴、就醫史與 BSRS-5；建檔時一併帶入、量表轉為療效追蹤基線，命中自殺意念題自動標高風險。
  • 個案管理：編號自動產生、身分證檢查碼驗證、主責心理師、風險等級、依生日自動判定未成年與法代欄位、結案摘要可列印。
  • 個案附件：轉介單、診斷證明、同意書掃描、衡鑑報告上傳（單檔 20MB）；隨機檔名落地、目錄不對外開放、下載逐次驗權並記入稽核。
  • 晤談紀錄：SOAP 格式 + 使用技術、家庭作業、風險標記；簽核定稿後比照病歷不可修改。
  • 心理量表：PHQ-9、GAD-7、BSRS-5、PSS-10、ISI，內建計分與切分點判讀；多次施測畫成折線圖；危險題命中自動拉高風險等級。
  • 處遇計畫、心理衡鑑報告書、轉介與結案後追蹤、同意書（5 份範本，手寫簽名與全文快照）。

營運與帳務

  • 收費與方案：預付堂數方案、單次收費、收據號、付款人別（自費／EAP／學校／社會局）。
  • 退費：另立退費單與原收費單勾稽，方案退費依剩餘堂數試算並同步停止扣次；報表以「收款 − 退費」計算實收。
  • 電子發票與補助核銷：發票號碼與日期、統編檢核、抬頭、載具、捐贈碼；補助方案可記方案序號、補助額與自付差額。
  • 報酬與扣繳：心理師鐘點給付單，試算代扣所得稅與二代健保補充保費，年度彙總供填報扣繳憑單。
  • 經營品質指標：爽約率、取消率、初談轉銜率、脫落率、平均晤談次數、心理師時段利用率。
  • 報表匯出：個案清單、晤談明細、收費明細、服務量、危機事件，皆可出 Excel／PDF／CSV，匯出記入稽核。

08.5各模組操作說明

每一頁在系統裡都有一段「這頁怎麼用」，這裡是同一份內容的完整清單，依左側選單順序排列。

在系統中打開任一頁，標題下方的「這頁怎麼用」點開即是下列文字；看熟了可以收合，系統會記住你的選擇。公開表單（線上預約、個案專區、初談問卷）的操作說明見前面 03 線上預約表單 與各自頁面上的指引。

每日作業

總覽今日排程與待辦提醒

  • 今天的排程與待辦提醒；紅色的是需要優先處理的（逾期未寫紀錄、申請取消、高風險個案等）。
  • 點任一列可直接跳到該筆資料。左側選單只會出現你有權限的模組。

我的工作台個人服務量、待辦與專業資格進度

  • 你個人的服務量、待辦與專業資格進度（繼續教育積分、督導時數）。
  • 進度條顯示距離執照更新所需時數還差多少；待辦指的是你自己要補的紀錄與報告。

行事曆一個月一眼看完晤談、團體、請假與可預約時段

  • 一個月一眼看完晤談、團體、請假與可預約時段；點任一天可看該日明細，並直接「在這天新增預約」。
  • 上方可切換月份、只看某位心理師。
  • 「訂閱網址」可把行事曆掛到手機或 Google 日曆；網址內容不含個案姓名，外流時可按「重設網址」讓舊網址失效。

預約排程週檢視：同一心理師或諮商室時段衝突會即時擋下；下方可設定每週可預約時段與請假

  • 週檢視：點任一張預約卡可看明細，並做「狀態異動／修改／刪除」。卡片顏色＝預約狀態，對照表在表格上方。
  • 右上「新增預約」排新的一筆；同一心理師或同一諮商室撞時段會直接擋下。
  • 下方「排班設定」用格子刷出每週可預約時段，不在格線上的時間（如 13:15-14:05）用「自訂時段」加，請假也在同一區登錄。
  • 上方下拉可只看某一位心理師。

諮商室使用表每間空間一週的使用狀況：時間、個案、心理師；視訊晤談不佔空間

  • 「單日總覽」一列一個時段、各諮商室並排，一眼看得出同一時段三間有沒有人；空白就是沒人用。
  • 「整週逐間」是每間諮商室一張整週表，適合看某一間的一週使用狀況。
  • 通訊（視訊）諮商不在所內進行，不會佔用諮商室，因此不會出現在這張表上。
  • 上方可切換週次。這頁只看不改，要調整請到「預約排程」。
  • 格子底色代表方案別（自費白底、市民方案藍底、國軍黃底、青壯粉紅底、EAP 綠底、馬太鞍／北捷土黃底），沒指定方案的以自費白底呈現。
  • 點任一格晤談可直接開啟修改預約，改完方案底色就會跟著變。

線上預約申請個案從預約表單或 LINE 送出的申請，確認後才寫進排程

  • 個案從線上表單或 LINE 送出的申請都落在這裡，先在這裡確認過才會進排程。
  • 按「處理」打開申請明細：初次預約的人要先「由申請資料建檔」，再選心理師與時段按「成立預約」；約不成按「未能成立（通知個案）」回覆。
  • 狀態「待處理」就是還沒處理完的；上方可用關鍵字、狀態、方案、心理師與送出日期篩選。

候補遞補取消釋出的時段，配對候補名單並直接通知

  • 這裡列出被取消而空出來的時段，右邊會算出有幾位候補人選符合。
  • 按「查看並通知」挑人發通知；對方回覆願意後，再按「直接排約」成立預約。
  • 想從候補名單反查時間，用「查任意時段候補」。
  • 候補名單本身是在個案或來電登記那邊登記的。

今日看板報到、完成與未到一鍵處理

  • 今天的每一筆晤談依序列出，個案來了按「狀態」改成已報到，談完改已完成，沒來改未到。
  • 改成「已完成」才會產生收費單、扣方案堂數，也才會出現在「待補紀錄」；「未到」依系統設定的比例計費。
  • 上方是今天各諮商室的使用狀況，管理者可在此編輯空間。

晤談提醒設定發送通道後可由系統送出；未設定時產生可複製的訊息供人工發送

  • 列出接下來需要提醒的晤談。已設定 LINE 或簡訊通道時可按「發送」由系統送出，未設定則按「複製訊息」自行貼到 LINE 傳給個案，再按「標記已通知」。
  • 「全部發送／複製全部」可一次處理整批。
  • 提醒提前幾小時發，在系統設定裡調。

待補紀錄與報告已完成但尚未撰寫的晤談紀錄，以及未完成的衡鑑報告

  • 已完成但還沒寫紀錄的晤談會留在這裡，按「撰寫紀錄」直接開紀錄表單。
  • 超過系統設定天數未補的會標紅，代表已逾所內規定的補記期限。
  • 下半部是尚未完成的衡鑑報告，可「撰寫報告」或「繼續編輯」草稿。

紀錄覆核實習心理師的晤談紀錄需經指定督導覆核後才定稿

  • 實習心理師的晤談紀錄要經指定督導覆核才定稿。
  • 按「覆核」看內容，通過就「覆核通過並定稿」，要改就「退回補正」並寫明原因。
  • 下半部是被退回、等實習生修改的紀錄。

個案訊息行政聯繫用（改期、繳費等）；晤談內容請勿於此討論

  • 與個案的行政聯繫（改期、繳費、提醒），點「開啟」進對話後送出訊息。

  • 個案沒綁定 LINE 時，回覆只會留在系統，他下次登入個案專區才看得到。
  • 晤談內容請勿在此討論，訊息內容會留在系統紀錄裡。

個案服務

來電登記與派案來電 → 評估派案 → 初談建檔；滿檔時列入候補

  • 新來電先按右上「新增來電登記」記下基本資料與主訴，之後在這一列往右走完流程。
  • 派案：指定主責心理師；滿檔時可先列候補。建檔：轉成正式個案。結束：沒有後續（未回覆、轉介他所等）。
  • 可先「產生問卷」請對方線上填初談問卷，填完這裡會顯示 BSRS 分數，超標會標⚠。

  • 個案清單，可搜尋姓名／編號／電話，並依狀態、主責心理師篩選。點「編輯」改基本資料。
  • 點個案姓名進「個案總覽」，晤談紀錄、處遇計畫、量表、附件、同意書都在那裡。

團體諮商團體名單、場次排程與出席；歷程紀錄僅帶領者、督導與管理者可讀

  • 按「填寫量表」由櫃檯或心理師代填；要請個案自己填，到個案總覽的量表頁「指派量表」產生連結。

  • 按右下「登錄事件」記下自傷、兒少保護、家暴等事件；「通報表」可產生可列印的通報書。

  • 法定通報有時限，逾期未通報的會標紅提醒。

安全計畫列管高風險個案是否都有現行安全計畫、是否逾期未檢視

  • 列出高風險個案是否都有現行安全計畫、是否逾期未檢視，逾期的排在最前面。

結案追蹤結案後的關懷追蹤點，逾期未追蹤列於最前

收費管理晤談完成後自動產生收費單；未到依設定比例計費

收據晤談結束後個案要收據就開一張；事後要補開、補印或重開都在這裡

  • 上半部是已收款但還沒開收據的收費單，個案要收據就按「開立收據」。

逾期催繳未收款超過設定天數的收費單，可整批產生或發送催繳訊息

  • 列出超過設定天數還沒收到錢的收費單。
  • 有 LINE／簡訊通道時按「發送催繳」由系統送出，沒有就「複製訊息」自行傳，再按「記錄已催繳」留痕。
  • 個案當場付款可直接在這裡「收款」。

方案管理預付堂數方案；完成晤談時自動扣次

  • 預付堂數方案（例如先買 10 次）。按「新增方案」設定堂數與金額後，晤談完成時自動扣一次。

合作單位與請款學校認輔、企業 EAP、社政委託案的契約、用量與月結請款

  • 先「新增合作單位」建立契約（學校認輔、企業 EAP、社政委託等），設定計價與用量上限。

  • 契約內容有變動時，草稿狀態的請款單可按「依現況重算」。

方案人次各心理師在限量方案的本週／本月已排人次，額滿者顯示下週餘額

  • 有人次上限的方案（多為公費補助案），各心理師本週／本月已排幾人次一目了然，額滿的會顯示下週餘額。

心理師收支依方案別結算每位心理師每月的服務量、收入、報酬與所方淨收

  • 依方案別結算每位心理師每月的服務量、收入、報酬與所方淨收。

統計報表月報：服務量、個案來源、收入與危機事件

系統

帳號權限行政人員預設不含晤談紀錄與危機事件模組

  • 按「新增帳號」建立員工帳號，勾選這個人能看到哪些模組；未勾的模組連選單都不會出現。
  • 行政人員預設不含晤談紀錄與危機事件（保密考量），可視需要調整。
  • 離職請用「停用」而不是刪除，才留得住稽核軌跡。

方案設定方案 × 主題 × 心理師的收費、資格與人次上限，皆可自訂

  • 一個「方案」＝一組收費規則：晤談時長、價格、資格限制、次數上限、心理師報酬怎麼算。排約選了方案，結束時間與費用就照它算。
  • 方案底下可再加「主題」（不同主題不同價）與「心理師費率」（同方案不同心理師抽成不同）。
  • 已經有預約在用的方案不要直接刪，改用「停用」，舊資料才不會對不上。

LINE 官方帳號串接設定、綁定管理與推播；所有通知都以 Flex Message 送出

  • 先在 LINE Developers 取得 Channel access token 與 secret 填進來，按「儲存憑證」再「驗證連線」。
  • 接著按「寫回 LINE 並測試」設定 Webhook，個案才能用 LINE 綁定與收通知。
  • 下方可管理個案／心理師的綁定，以及調整提醒時間與推播開關；未設定憑證時所有通知只會產生文字紀錄，不會對外送出任何個資。

Google 表單同步原本的 Google 預約表單填完後，自動寫入後台的線上預約申請

  • 讓原本的 Google 預約表單填完後自動寫進後台的「線上預約申請」，櫃檯不用再謄一次。
  • 步驟：按「複製程式碼」→ 貼到該 Google 表單的 Apps Script → 存檔並授權。密鑰留空表示不開放同步。
  • 方案／主題／心理師以選項文字自動對應，對不到時仍會收單並標示「需人工指定」，資料不會掉。

系統設定所別資訊、收費預設值、選項清單與同意書範本

  • 所別資訊、收費預設值（如未到計費比例、紀錄補記天數）、各種下拉選項清單與同意書範本都在這裡。
  • 改動會立即影響全所，每個欄位下方都有說明。

資料匯入把舊系統或 Excel 名冊搬進來；預覽階段完全不寫入，有任一列錯誤即整批拒絕

  • 把舊系統或 Excel 的資料搬進來：先「下載範本」照格式填好，再「上傳並預覽」。
  • 預覽會逐列檢查，有問題的列會標出原因，確認沒問題才按「確認匯入」，不會半套寫入。
  • 看不懂欄位就按「欄位說明」。建議先在測試環境試一次。

紀錄保存與歸檔結案滿保存年限的個案，可依所內政策歸檔或銷毀

  • 結案滿保存年限的個案會列在這裡，依所內政策決定歸檔或銷毀。
  • 銷毀不可復原，請先確認法定保存年限（通常自結案起算）。

稽核軌跡誰在何時調閱或異動了哪些紀錄（僅管理者可看）

  • 誰在何時調閱或異動了哪些紀錄，僅管理者可看，用於個資稽核與爭議釐清。

09系統、資料與維運

帳號權限

19 個模組逐一勾選，可全選、全部取消或一鍵套用角色預設（行政不含晤談紀錄與危機事件）；帳號名稱事後可更正；不可停用最後一位管理者。

密碼與重設

密碼在資料庫只存加密後的雜湊值，任何人都查不回原本的密碼。忘記密碼時由管理者按「重設密碼」，可自訂或自動產生 8 碼，新密碼當場顯示一次交給本人，重設行為記入稽核。

系統設定

所別資訊、收費預設、責任通報時限、扣繳費率、提醒發送通道、選項清單、前台文字、諮商室、同意書範本等皆可自改。

舊資料匯入

個案名冊、晤談排程、收費明細、量表施測四種 Excel／CSV：下載範本 → 上傳預覽 → 確認匯入，任一列錯誤即整批拒絕，檔案不落地。

備份

每日自動備份保留 14 份 + 異地鏡像，個案附件一併同步；備份後回收空間並清理孤兒附件。

技術架構

Node.js + Express 5 + SQLite（WAL），JWT HttpOnly Cookie；前端原生 SPA 無框架。

上線前檢查

改完程式先跑冒煙測試（拋棄式資料庫，不碰正式資料），涵蓋權限、排班、預約衝突、收費退費、附件與備份。

10目前關閉與待辦

功能與資料都還在，只是暫時不顯示；需要時改一個設定即回復。

  • 已關閉——實習心理師督導覆核：所內暫無實習生，「紀錄覆核」頁與帳號設定裡的實習生欄位都不出現。
  • 已關閉——團體諮商、請假與繼續教育、督導紀錄、合作單位請款、逾期催繳、危機事件與通報、安全計畫列管：不出現在導覽列、總覽看板與個案分頁。
  • 待辦——視訊平台 API 串接（目前為貼上會議室連結，未自動開房）。
  • 待辦——電子發票開立 API 串接（目前為欄位登錄與收據列印，發票號碼需由開立系統取得後回填）。

名詞白話說明
方案一組收費規則，不只是價錢：還含晤談時長、資格限制、次數上限、心理師報酬怎麼算。例如「個別 50 分鐘 2000」是一個方案。
主題方案底下的細分項目（如親密關係、生涯議題），可以覆寫方案的預設金額。

收費單／收據收費單是所內的帳（誰欠多少、收了沒）；收據是給個案的憑證，有正式流水編號。兩者分開，一張帳可以事後才補開收據。
SOAP晤談紀錄的標準格式：主觀陳述、客觀觀察、評估、處遇計畫四段。
量表（PHQ-9、BSRS-5⋯⋯）標準化的心理篩檢問卷，系統內建計分與判讀切分點，多次施測會自動畫成折線圖。
稽核軌跡系統自動留下的操作紀錄：誰、何時、看了或改了什麼。用來事後查核，任何人都刪不掉。
LINE 官方帳號店家用的 LINE 帳號（本所是 @032cjyby），可以讓系統程式化地發訊息給加入好友的人。
Flex MessageLINE 的卡片式訊息，可以放標題、資訊欄和按鈕，比純文字好讀也好按。
Webhook「有事請通知我」的回撥網址。設定給 LINE 之後，有人加好友或傳訊息，LINE 就會即時打這個網址通知系統。
Channel access token／secretLINE 發給我們的兩把鑰匙：token 用來代表官方帳號送訊息，secret 用來驗證「這則通知真的是 LINE 送來的」。等同密碼，只在後台輸入一次。
Token（一次性連結裡的）一串隨機字，代表「某個人的某次操作」，有效期一到就作廢。用它取代把身分寫在網址上，網址外流也換不出個資。
userIdLINE 給每位使用者的固定代號。系統靠它才能把訊息推給正確的人，所以刻意不讓它出現在網址列。
綁定把系統裡的某位個案，和某個 LINE 帳號對上。做法是櫃檯發 6 碼綁定碼，個案在聊天室輸入。
Apps ScriptGoogle 表單內建的程式功能。貼上一段我們提供的程式碼後，表單每收到一筆回應就會自動送進本系統。
.ics 訂閱行事曆的通用格式。訂閱一次，班表變動會自動同步到 Google 日曆或 iPhone 行事曆。
API系統之間互相呼叫的介面。文件裡出現 /api/⋯ 的地方，指的是程式對程式的入口，不是給人點的網頁。
SPA單頁式網頁應用：整個後台其實是一個網頁，切換頁面時只換內容不整頁重載，所以操作起來像 App 一樣快。
